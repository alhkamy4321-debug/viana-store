# متجر فيانا Viana الإلكتروني

متجر إكسسوارات بثلاث صفحات، بتصميم عربي (RTL) وألوان درجات زرقاء فاتحة ناعمة.

## الصفحات
- `index.html` — الصفحة الرئيسية (الواجهة، الخدمات الثلاث، منتجات مختارة)
- `products.html` — صفحة المنتجات (6 منتجات + فلترة + سلة مشتريات)
- `contact.html` — صفحة التواصل (واتساب، العنوان، نموذج رسالة، خريطة)

## الملفات
- `assets/style.css` — التصميم والألوان
- `assets/script.js` — السلة، الفلترة، القائمة، ونموذج التواصل
- `assets/*.jpg` — صور المنتجات والواجهة (محفوظة محليًا داخل المشروع)

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تعديل البيانات
- رقم واتساب: ابحث عن `966537543144` في ملفات HTML و `script.js` (الرقم بصيغة دولية؛ المعروض للزائر `0537543144`).
- العنوان: ابحث عن «الطائف» وعدّله في ملفات HTML.
- الأسعار والمنتجات: عدّل بطاقات المنتجات في `index.html` و `products.html` (الخصائص `data-price` و `data-name` و `data-image`).
- الألوان: عدّل المتغيرات في أعلى `assets/style.css` تحت `:root`.
